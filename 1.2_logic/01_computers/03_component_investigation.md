## Answers: component functions

The specifications below identify what to record; they are not measurements or specifications of an inspected computer.

| Component | Function | Key specification to record from the lab device |
|---|---|---|
| CPU | Executes instructions, performs arithmetic and logical operations, and coordinates processing. | Exact model, core/thread count, clock frequency, and socket. |
| RAM | Holds active programs and data temporarily so the CPU can access them quickly; normally loses contents when power is removed. | Capacity in GB, DDR generation, rated transfer rate, and module count. |
| Storage | Retains the operating system, applications, and user files without power. | Model, capacity, SSD or HDD, interface such as SATA or NVMe, and HDD rotation speed if applicable. |
| Motherboard | Connects components and provides communication pathways, sockets, slots, and firmware support. | Model, form factor, CPU socket, chipset, and supported memory type. |
| Power Supply | Converts mains AC into regulated DC power for internal components. | Model, rated output in watts, efficiency certification if present, and connectors. |
| Cooling | Transfers heat away from components to help keep them within operating temperatures. | Air or liquid cooling, fan size/count, cooler model, and CPU compatibility. |
