## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

---

## Answers

### Hardware
Hardware means the physical parts of a computer that can be seen and touched. Examples include the processor, motherboard, memory modules, storage drives, keyboard, mouse, and monitor. Each component performs a particular job, such as processing instructions, storing information, or accepting input. Hardware also includes cables, power supplies, and cooling equipment that allow the system to operate reliably.

### Software
Software is the collection of programs and instructions that tells computer hardware what to do. It includes operating systems, applications, utilities, and device drivers. For example, an operating system manages memory and files, while a web browser displays websites. Unlike hardware, software is not a physical component; it is represented by data stored on a device and executed by a processor.

### Interaction
Hardware and software work together to carry out tasks. When a user types a letter, the keyboard sends a signal that software interprets as input. The operating system and application process this input using the CPU and RAM, then send output to the display. Drivers help software communicate with particular devices. Saving the document writes its data to persistent storage.
