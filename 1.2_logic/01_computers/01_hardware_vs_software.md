# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

Hardware refers to the physical parts of a computer system that people can see and touch. Examples include the keyboard, mouse, monitor, processor, motherboard and storage drive. Each component performs a particular function, such as entering information, processing data or displaying results. Hardware also includes external devices, such as printers and speakers, which connect to a computer to provide additional functions.

---

## Explain Software
Write **at least 50 words** explaining what software is.

Software is a collection of programs and instructions that tells a computer how to perform tasks. Unlike hardware, software is not a physical object that people can touch. System software, such as Windows or macOS, manages the computer’s resources. Application software, such as Microsoft Word or a web browser, helps users complete specific activities, including writing documents and accessing websites.

---

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Hardware and software work together to carry out tasks. Software provides instructions, while hardware executes those instructions. For example, when a user types in a word processor, the keyboard sends input to the computer. The software processes this input, and the monitor displays the text. The operating system coordinates communication between applications and hardware, allowing components such as storage drives and printers to function correctly.
